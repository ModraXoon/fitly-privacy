FITLY

Privacy Policy

Updated: September 30, 2026 · Contact: contact@xoonex.dev

What Fitly does

Fitly is a Chrome extension that reads job postings on supported sites (LinkedIn, Kariyer.net, and Indeed) and compares detected job keywords with your CV. Local keyword coverage is not an ATS pass prediction or a hiring probability. You can edit and copy application-answer drafts for manual entry. Form-field automation is disabled in this release pending real-browser safety checks.

Data stored locally

Fitly stores the following information on your device using Chrome's chrome.storage.local API:

  • CV profiles and resume text that you enter.
  • Job title, company, URL, and draft snippets only for tracking entries you create.
  • Language, provider, consent, and analysis settings.
  • Application tracking entries.
  • An optional external-provider API key.

The current job description is held in memory while the panel is open and is not persistently stored by Fitly. A tracking entry you create saves the job title, company, URL, and generated draft snippets, but not the full job description.

API-key warning: Provider API keys are stored unencrypted in the extension's local browser storage. Chrome isolates extension storage from ordinary web pages and other extensions, but malware, developer tools, a compromised browser profile, or someone with access to your unlocked device may expose it. Use limited keys and rotate them regularly.

Optional external AI providers

Fitly has no Fitly-operated backend, analytics endpoint, advertising endpoint, or telemetry service. By default, local heuristic analysis does not send CV or job text to an AI provider.

If you explicitly select Groq, Google Gemini, or OpenAI and grant provider-bound consent, Fitly sends the following directly from your browser to that selected provider for analysis:

  • Your CV text.
  • The current job description.
  • Your IP address as part of the HTTPS connection.
  • Your provider API credential for authentication.

The transfer occurs only after provider selection, explicit consent, and an analysis request. Provider handling is governed by the provider's policy: Groq, Google Gemini API, or OpenAI.

What Fitly does not do

  • Fitly does not sell user data.
  • Fitly does not use analytics, tracking pixels, advertising, or telemetry.
  • Fitly does not access browsing history outside supported job-board pages.
  • Fitly does not automatically submit job applications.

Application preparation

Automatic form filling, step navigation, and submission are disabled in this release. Fitly does not modify application form fields or activate submission controls. You may edit and copy drafts, review each fact, then complete and submit applications yourself.

Retention and deletion

Local data remains in your browser profile until you remove it. You can delete individual CVs and tracking entries in Fitly, clear a stored API key in Settings and save, clear extension storage in Chrome, or uninstall Fitly to remove its local data.

Permissions

  • sidePanel: displays Fitly beside the current page.
  • storage: stores CVs, settings, consent state, credentials, and tracking data locally.
  • activeTab and job-board host access: read supported job postings after you open the extension. Form-field modifications are disabled.
  • AI-provider host access: sends an analysis request only to the provider you select and approve.

Children's privacy

Fitly is not directed to children under 13 and does not knowingly collect information from children.

Changes and contact

Material changes will be published on this page with an updated effective date. For privacy questions or deletion assistance, email contact@xoonex.dev.
